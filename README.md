## Pumpkin Patch Party

A kid-friendly Halloween game with a clickable browser interface, written in Python. Pick one of three pumpkins in each of 50 rounds. Each pick randomly gives you 1, 2, or 3 candies. Collect at least 100 candies to win; you never lose candy, and you can start a new game whenever you like.

Start the game server from this folder with:

```bash
python3 halloween_game.py
```

Then open `http://localhost:8000` in your browser. In a remote VS Code workspace, open port 8000 from the Ports panel. Click a pumpkin to pick it; your round and candy total are shown above the pumpkins.
